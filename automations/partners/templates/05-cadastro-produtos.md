# Cadastro de produtos — {{nome_loja}}

Modelo inicial para revisão do time. Aplicável somente a lojas que NÃO são clientes Instabuy.

Projeto: [card principal]({{url_card_principal}}). ID de vínculo: `{{id_tarefa_pai}}`.

## O que fazer

Realizar o cadastro inicial de itens para a loja nova, a partir da base e das informações recebidas e validadas com o responsável.

## Como agir

Confira primeiro a resposta “Já é cliente instabuy?” no principal. Se estiver marcada como Sim, registre a divergência para revisão; não execute esta etapa nem altere outros cards automaticamente. Para clientes novos, siga o procedimento interno de cadastro, confira os campos necessários e corrija inconsistências antes de encaminhar à Qualidade. Registre o que foi realizado e o que permanece pendente.

## Para concluir

O cadastro deve estar disponível e conferido conforme o escopo, com validação registrada. Conclua a tarefa no ClickUp para seguir à Qualidade.
